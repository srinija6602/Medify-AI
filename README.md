# Medify-AI
AI-Based Healthcare Information Assistant🩺

## AI-Based Healthcare Assistant

Medify-AI is an AI-powered healthcare assistant that provides general health information and helps users understand common symptoms.

### Features
- AI Chatbot for health-related questions
- Symptom Checker
- User-friendly Streamlit interface
- Local AI model integration

### Technologies Used
- Python
- Streamlit
- Ollama
- Large Language Model (LLM)

### How to Run
1. Install Python.
2. Install the required packages.
3. Install Ollama and download the configured AI model.
4. Run the application using:

```bash
streamlit run app.py
```

### Disclaimer
Medify-AI provides general health information and is not a substitute for professional medical advice or emergency care.
